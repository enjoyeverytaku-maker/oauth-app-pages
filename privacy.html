プライバシーポリシー

本ポリシーは、Kabureco FlowWorks（以下「運営者」）が自社の業務管理用に運用するツール「ClaudeCode Book CEO」（以下「本ツール」）における Google ユーザーデータの取り扱いを定めます。

1. 利用者

本ツールは運営者本人のみが使用し、運営者本人の Google アカウントにのみ接続します。第三者のアカウントには接続しません。

2. 取得する情報

Gmail API の読み取り専用権限（gmail.readonly）を使い、特定の送信元（受託案件のプラットフォーム等）から届いたメールについて、次の情報のみを取得します。

  • 件名・送信元・日時
  • Gmail が提供する本文の抜粋（snippet）

メールの送信・削除・変更、ラベルの変更は行いません。

3. 利用目的

運営者自身の受託案件の進捗（返信の有無・契約状況など）を管理するためだけに利用します。広告、販売、プロファイリング、AI モデルの学習には利用しません。

4. 保存と共有

取得した情報は、運営者が管理する非公開の作業環境にのみ保存し、第三者に販売・提供・共有しません。認証情報（トークン）は公開されない場所で管理します。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から取得した情報の使用および他アプリへの転送は、限定使用の要件を含め、Google API Services User Data Policy に準拠します。

6. 削除

運営者は、Google アカウントの「サードパーティ製のアプリとサービス」から本ツールのアクセス権をいつでも取り消せます。保存した情報は不要になった時点で削除します。

7. 改定

本ポリシーを改定する場合は、このページを更新します。
